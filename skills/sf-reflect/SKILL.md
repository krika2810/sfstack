# sf-reflect

Spawn three parallel review passes over the active transcript:

1. **Friction pass**: where did the run stall, backtrack, or burn tokens? Root-cause each stall.
2. **Correction pass**: every time the human corrected the agent - what rule would have prevented the correction?
3. **Platform pass**: every governor-limit, order-of-execution, deployment, or test surprise - which skill or principle should have predicted it?

Route each learning to a concrete edit: an existing skill's body, a principle, a playbook, or the project's Feature Map gotchas. One learning = one edit, small and specific. Apply the edits in the same session and show the diff. Learnings with no edit home go in the report as open questions; they are not written anywhere "for later".
